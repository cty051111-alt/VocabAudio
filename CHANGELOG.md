# Changelog

## v2.0.0-beta

- Added the original light/dark office UI, persistent preferences and repeat controls.
- Preserved vocabulary extraction and audio generation from v1.1.
- Added Windows portable build with a waited executable self-test and report.
- Release remains a prerelease; online audio and interactive Windows uninstall require manual validation.

## v1.1.0 — GitHub source release (2026-10-18)

- Packaged the user-tested Windows v1.1 source as a public-repository-ready project.
- Added bilingual documentation, open-source license, offline tests, CI and issue templates.
- Retained the original Tkinter app, document parsing, audio processing and Windows launch scripts; no functional refactor was performed.
- External pronunciation downloads remain dependent on provider reachability and use conditions.

## Earlier internal builds

- v1.1: fixed Windows launcher script and PDF module import compatibility.
- v1.0: initial PDF/DOCX/TXT extraction, vocabulary editing and MP3 stitching.
