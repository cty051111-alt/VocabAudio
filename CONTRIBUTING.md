# Contributing / 贡献指南

Thanks for helping! 请优先提供可复现的问题报告。

1. Search existing issues, then open a bug report with the operating system, Python version, file format, expected and actual results, and **redacted** traceback.
2. For code changes, fork/branch, keep PRs scoped, add or update offline tests, and run `python -m pytest -q`.
3. Do not commit personal Word/PDF files, private data, API tokens, or third-party pronunciation audio without explicit redistribution rights.
4. Do not bypass authentication, rate limits, or terms of external dictionary providers. Prefer documented and suitably licensed audio sources.
5. Add screenshots to issues only after removing personal information and file paths you do not wish to disclose.

Maintainers review submissions when available; no response-time guarantee is offered.
