# Image OCR Implementation Plan

> Implement in the current chat; the user requested the complete upgrade.

**Goal:** Import or paste an image, review its recognized text, and send English vocabulary to the existing audio workflow while preserving both themes.

**Architecture:** A separate `image_ocr.py` module handles local image validation, OCR and geometric line grouping. A new Qt desktop UI replaces the old Tkinter controls with modern cards, buttons, inputs and controls following the user's November 2 request. The UI runs recognition in a worker thread and shows an editable review dialog before changing the vocabulary list. OCR models are included in the Windows build; pictures never go to a service.

**Tech Stack:** Python 3.13, PySide6 Essentials, Pillow, RapidOCR 3.10, ONNX Runtime CPU. Rounded cards (10px), outlined secondary buttons (6px), flat primary buttons, consistent 38px controls, spacious typography and both existing theme directions.

### Task 1: Local OCR core
- Add `image_ocr.py` with image size limits, EXIF orientation correction, transparent background handling, lazy local engine, and geometric grouping of recognized blocks.
- Add offline tests for invalid/blank images, Chinese and English text, column spacing, transparent images, review extraction, and a real generated image.
- Pin supported dependency ranges in `requirements.txt`.

### Task 2: UI integration
- Add image import and clipboard buttons to `app.py`, preserving the existing layout and colors.
- Add side-by-side image/text review, editable text, copy/save text, and replace/append word-list actions.
- Disable conflicting mutations during background work; cancellation discards pending OCR results.
- Exercise real OCR and UI on both themes, including cancellation and blank-image results.

### Task 3: Build and deliver
- Include OCR models, ONNX binaries and third-party notices in both build commands.
- Extend offline EXE self-test to recognize a generated vocabulary image, without network.
- Update Chinese/English documentation and release notes for 2.1 Beta; avoid overwriting the old release.
- Run all tests, build the Windows EXE, run its OCR self-test and package a portable ZIP plus source archive under outputs.
- Report verified scope and any remaining limits. Do not claim an online pronunciation test unless performed.
