# VocabAudio 2.0.0-beta

- Redesigned professional office UI with blue waveform app icon.
- Light and dark modes with locally saved preferences.
- Headword preview table, inline edit entry point, manual add/remove/reorder.
- Select US/UK accent, reading speed, pause length, repeat 1–5 times, export MP3.
- Safer uninstaller, allow-listed program files and app-owned settings only.
- Windows PyInstaller one-file release build workflow.
- 11 offline tests passing (includes preferences and repetition composition).

**Beta limitations:** True online dictionary audio download not exercised in the build environment; Windows EXE and uninstall script await on-device Windows testing. Native WPS and image-only PDF require conversion/OCR. The preview does not provide automatic IPA.
